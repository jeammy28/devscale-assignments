# Devscale Assignments

Assignment collection for Fullstack JavaScript Batch 13 at Devscale.

## Structure

- `assignment-1/` - Discount calculator and temperature converter CLI (TypeScript, Bun, @inquirer/prompts)

## Running an assignment

```sh
cd assignment-1
bun install
bun run src/index.ts
```

## Requirements

- Bun
- Clean checks before submitting: `bun check`, `bun lint`, `bun fmt`
